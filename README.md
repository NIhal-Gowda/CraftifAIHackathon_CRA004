# RetailPulse AI — Computer Vision Queue & Shelf Analytics
THIS PROJECT WAS POSSIBLE BECAUSE OF 1.MOHAMMED RAIYAN , 2. NIHAL.N , 3. PAVAN KUMAR S
An edge-ready computer vision solution for real-time queue length tracking, customer density monitoring, and shelf stock management in retail environments.

---

## 🎯 Track & Problem Statement

* **Track:** Track #3 — Retail Shelf and Queue Monitor (PipeGen)
* **Problem:** Retail stores lose substantial sales and compromise customer experience due to unmonitored empty shelves and excessively long checkout queues. Manual monitoring in large retail settings is inefficient and reactive.
* **Solution:** An automated vision intelligence pipeline built using computer vision models (PipeGen / YOLOv8) and Streamlit that processes store camera streams in real-time, counts queue traffic, detects queue length thresholds, and triggers instant alerts on an interactive management dashboard.

---

## ✨ Key Features

* **Real-time Queue Counting:** Detects and counts individuals in checkout lines using vision detection models.
* **Dynamic Threshold Alerts:** Displays real-time status banners and warnings when queue density exceeds predefined customer thresholds.
* **Interactive Monitoring Dashboard:** Built with Streamlit for clean visualization of bounding boxes, counts, and metric overviews.
* **Edge-Deployable Pipeline:** Standardized detection configuration suitable for deployment via PipeGen on edge compute hardware.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Python 3.10+
* **Framework / Tools:** PipeGen, Streamlit
* **Computer Vision / AI:** OpenCV, Ultralytics YOLOv8
* **Dependencies:** `streamlit`, `ultralytics`, `opencv-python`, `numpy`
