## 🤝 Dual-Redundancy Architecture (Cross-Linked Reference)
To guarantee high availability and prevent single-point failures in resource-constrained edge-computing deployments, this project is engineered with a **Dual-Execution Subsystem**:

1. **Production Visual Application (`HACKATHON.py`)**
   * **Core Stack:** Python, Streamlit, OpenCV, YOLOv8 Neural Network Weights.
   * **Function:** Ingests live retail camera frame matrix links, runs machine learning object detection to track human coordinates, draws localized bounding boxes, and triggers supervisor layout warnings.

2. **Cloud Pipeline Compiler Simulator (`FIRMGEN_CORE_SIMULATOR.ipynb`)**
   * **Core Stack:** Pure Python Logic Layer, JSON Data Mapping Serialization.
   * **Function:** Functions as our robust architectural safety net. If remote platform registries encounter installation package distribution blocks or severe network latency drops, this compiler subsystem automatically intercepts the pipeline constraints. It maps data definitions natively and compiles the pipeline graph without crashing the host device.
